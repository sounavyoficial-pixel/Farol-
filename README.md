# Farol- / Farol-

A minimal interactive experimental interface inspired by a floating navigation beacon, designed for a lightweight UI concept with voice/chat behaviors and a compact “mira” interaction system.

Uma interface experimental minimalista inspirada em um farol flutuante, pensada para um conceito de navegação leve com interações de voz/chat e um sistema compacto de “mira”.

## Overview / Visão geral

This project is a single-page prototype for a floating orb called “Farol” that expands into an OPERA-style panel. It includes a subtle UI, a draggable detector, a guided interaction mode, and a chat area for a conversational assistant.

Este projeto é um protótipo de página única para uma órbita flutuante chamada “Farol”, que se expande em um painel no estilo OPERA. Ele inclui uma interface discreta, um detector arrastável, um modo de interação guiada e uma área de chat para um assistente conversacional.

## Features / Funcionalidades

- Floating orb with drag interaction / Órbita flutuante com interação de arrasto
- Expandable interface panel / Painel expansível
- Interaction “Mira” mode / Modo de interação “Mira”
- Chat area / Área de chat
- Voice input button / Botão de entrada por voz
- Visual feedback with states like GO and STOP / Feedback visual com estados como GO e STOP
- Mobile-friendly layout / Layout compatível com celular
